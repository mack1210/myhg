A LITTLE GUIDE FOR FRIENDS

설정은 가볍게.
비밀은 금고에.

AI를 쓰다 늘어난 설정과 API 키.
재료 목록, 조리법, 금고만 떠올려 보세요.
chezmoi와 환경변수 관리가 쉬워집니다.

그림으로 이해하기 ↓ AI에게 부탁하는 법 ↗
THE ONE IDEA

매번 설정을 복사하는 대신, 값은 한곳에 모으고 양식으로 채워요.

01

도시락을 만든다고 생각해 보세요.

chezmoi는 재료 목록을 읽고 조리법에 맞춰 설정 파일을 만드는 도구예요.

  1. 01 / INGREDIENTS

    재료 목록

    앱 이름 같은 값을 모아요.

    .chezmoidata.yaml
  2. 02 / RECIPE

    빈칸이 있는 양식

    어디에 넣을지 정해요.

    .tmpl
  3. 03 / CHEZMOI →

    완성된 설정 파일

    chezmoi가 빈칸을 채워요.

    .friend-ai.env
  4. 04 / READY TO USE

    프로그램에 전달

    앱이나 셸이 파일을 읽어요.

    환경변수 → AI 앱

●환경변수는 프로그램이 읽는 이름표예요. 데이터 파일을 만드는 것만으로 자동 등록되지는 않아요.

02

이름 하나 바꾸면, 설정도 따라와요.

아래 값을 바꾸고 재료 → 양식 → 결과를 눌러 보세요.

나의 작은 AI 앱

한곳에 적은 값을 여러 설정에서 함께 쓸 수 있어요.

미리보기 전용이에요. 실제 설정은 바뀌지 않아요.

.chezmoidata.yaml

app:
  name: "friend-ai"
  environment: "practice"

private_dot_friend-ai.env.tmpl

APP_NAME={{ .app.name | quote }}
APP_ENV={{ .app.environment | quote }}

.friend-ai.env

APP_NAME="friend-ai"
APP_ENV="practice"

여기에 값을 모아요. 다른 양식에서도 같은 값을 꺼내 쓸 수 있어요.

{{ .app.name }}은 “목록의 app 안에서 name을 꺼내 줘”라는 뜻이에요.

03

비밀값 대신, 금고 칸 이름을 적어요.

API 키는 AI 서비스에 들어가는 열쇠예요. pass는 그 열쇠를 보관하는 금고예요.

KEEP THE KEY IN THE VAULT

공유하는 건 조리법까지.

Git은 설정 양식의 변경 기록이에요.
재료 목록과 양식은 공유하고,
실제 키가 들어간 완성 파일은 내 컴퓨터에 둬요.

  1. pass에 실제 키를 보관해요.

    예: api/openai/api_key라는 칸에 저장해요.

  2. 재료 목록에는 칸 이름만 적어요.

    비밀값 없이 “어디에서 꺼낼지” 알려 줘요.

  3. 필요할 때 chezmoi가 꺼내 채워요.

    완성 파일에는 실제 키가 들어가요. 이 파일과 출력 내용은 공유하지 않아요.

04 / ASK YOUR AI

AI에게는 양식을,
비밀은 금고에.

설정 구조와 가짜 값, 원하는 결과를 알려 주세요.
오른쪽 요청문을 복사해서 시작해 보세요.

친구에게도 공유할 수 있는 요청문
chezmoi로 AI 앱 설정을 관리하고 싶어.
앱 이름은 .chezmoidata.yaml의 app.name에서 읽어 줘.
API 키는 pass의 api/openai/api_key에서 읽도록 해 줘.
실제 비밀값을 읽거나 출력하지 말고, 가짜 pass로 템플릿을 검사해 줘.
기존 암호화 방식은 유지하고, 실제 파일 적용 전에는 변경안을 보여 줘.
05

이제 직접 만들어 볼까요?

처음에는 비밀값 없이, 임시 폴더에서 연습해요.

준비물: chezmoi가 설치된 Bash · 아래 단계는 같은 터미널에서 순서대로 진행해요.

01실습용 폴더 준비하기

실제 홈 설정과 분리된 작은 작업실을 만들어요.

demo_dir=$(mktemp -d)
mkdir -p "$demo_dir/source" "$demo_dir/home"
printf '{}\n' > "$demo_dir/config.json"
cm() {
  chezmoi --config "$demo_dir/config.json" \
    --source "$demo_dir/source" --destination "$demo_dir/home" \
    --cache "$demo_dir/cache" --persistent-state "$demo_dir/state.boltdb" "$@"
}
02재료 목록과 양식 저장하기

아래 경로에 파일 두 개를 만들고 각각 내용을 저장해요.

재료 목록

$demo_dir/source/.chezmoidata.yaml

app:
  name: friend-ai
  environment: practice

양식

$demo_dir/source/private_dot_friend-ai.env.tmpl

APP_NAME={{ .app.name | quote }}
APP_ENV={{ .app.environment | quote }}

dot_은 파일 이름의 점, .tmpl은 양식, private_는 다른 사용자의 읽기 권한을 제한하는 표시예요.

03설정 파일 만들고 프로그램에 전달하기

미리 확인한 뒤, 임시 폴더에 적용해요.

# 먼저 완성될 내용을 확인합니다. 이 실습에는 비밀값이 없습니다.
cm execute-template < "$demo_dir/source/private_dot_friend-ai.env.tmpl"
cm diff
# 확인한 내용을 임시 폴더에 만듭니다.
cm apply

완성 파일: $demo_dir/home/.friend-ai.env

APP_NAME="friend-ai"
APP_ENV="practice"

현재 Bash에서 파일을 읽으면 이후 실행하는 프로그램도 값을 받아요.

set -a
. "$demo_dir/home/.friend-ai.env"
set +a
printf '%s\n' "$APP_NAME"
# friend-ai

. 명령은 파일을 코드로 실행하므로 직접 만든 신뢰할 수 있는 파일에만 사용해요. 프로그램마다 .env를 읽는 규칙은 다를 수 있어요.

04준비가 됐다면, pass 연결하기

pass 설치와 GPG 금고 초기화를 마친 뒤 pass insert api/openai/api_key를 실행하고 입력 창에 키를 입력해요.

기존 재료 목록에 아래 항목을 합쳐요. 실제 키 대신 금고 경로만 적어요.

secrets:
  api:
    openai_api_key: api/openai/api_key

양식에 한 줄을 추가하면 pass에서 키를 꺼내 채워요.

OPENAI_API_KEY={{ pass .secrets.api.openai_api_key | quote }}

이제 diff나 execute-template 출력에도 실제 키가 나올 수 있어요. 완성 파일과 출력 내용은 Git·채팅·공유 화면에 올리지 않아요.

quote는 큰따옴표로 감싸는 기능이에요. 암호화 기능은 아니며, 특수문자가 있는 값은 사용할 프로그램의 파일 규칙을 확인해요.

05내 설정에 연결하고 예제 검사하기

chezmoi source-path가 알려주는 폴더에 실제 .chezmoidata.yaml을 둬요. 기존 항목과 합치고 같은 이름의 항목을 중복해서 만들지 않아요.

cgmoi 방식은 일반 설정은 데이터에, 비밀은 pass에 두며 이미 암호화된 양식은 암호화 상태를 유지해요.

실제 파일에 chezmoi apply를 하기 전에는 대상·변경 내용·자동 커밋 및 푸시 설정을 확인해요.

이 저장소의 예제 검사

python3 -m unittest discover -s tests -v

Python 3와 chezmoi로 가짜 값을 검사해요. 실제 홈 설정과 금고는 사용하지 않아요.

템플릿 안내 ↗ 공유 데이터 파일 ↗ pass 연결 안내 ↗ execute-template ↗
